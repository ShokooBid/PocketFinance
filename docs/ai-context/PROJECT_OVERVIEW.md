# Project overview

_Last verified against the code on 2026-11-25. Branch:
`fix/issue-137-currency-account-edit`, one commit ahead of `main`._

## What it is

PocketFinance is a personal-finance mobile app. One person uses it to track
income, expenses, and transfers across manually named accounts such as "BMO" or
"Cash". It does not connect to a bank. It is a **pre-release
portfolio/learning project** owned by ShokooBid. GitHub reports `main` as
unprotected on the current private plan.

- **Name history:** the project was originally called **PocketLedger**. Commit
  `a87531d` (PR #110) renamed it to PocketFinance. The Git remote is
  `github.com/ShokooBid/PocketFinance`. Native app identity:
  `com.shokoobid.pocketfinance`, URL scheme `pocketfinance`.
- **Workflow:** development is issue-driven. Every change has a GitHub issue and
  its own branch, and is squash-merged through a PR. Issue numbers (#64, #93,
  #117, …) appear throughout the code comments and docs.

## Product principles (from docs and code)

1. **Exact money.** Amounts are integer minor units, one currency per user, and
   there is no foreign-exchange conversion.
2. **Explicit ownership.** The server derives the owner from the session and
   enforces ownership in both the API and SQL.
3. **Manual first.** Statement import and AI come later. Anything generated
   becomes a draft that requires confirmation.
4. **Entry-first UX.** "Add" is the home screen after sign-in. The bottom bar
   holds Add, History, and Overview. The avatar menu holds Accounts and Sign out
   (or Exit demo).
5. **Credential-free demo.** An in-memory demo runs on web or in Expo Go with no
   backend.

## Design language

The design is minimal, modern, and mobile-first, with a purple/pink palette.
Tokens live in [apps/mobile/src/theme.ts](../../apps/mobile/src/theme.ts):

- primary `#7043D9`
- accent `#EE3998`
- gradient from `#F63898` to `#9B80FF`
- text `#30213F`
- background white
- radius 22, pill radius 999
- 48px touch targets

Light mode only (`userInterfaceStyle: "light"`). Category icons are bundled SVGs
generated by `npm run icons:generate`. Detailed UX decisions are in
[docs/mobile-redesign/ux.md](../mobile-redesign/ux.md). The confirmed product
answers are in
[docs/mobile-redesign/README.md](../mobile-redesign/README.md#confirmed-product-decisions).

## Stack (verified from package manifests)

| Layer       | Technology                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mobile      | Expo SDK ~58, React Native 0.88, React 19.3, Expo Router (typed routes), Expo SecureStore, react-native-nitro-google-signin, react-native-ui-datepicker, Zod 4 |
| API         | Node 22 (≥22.13, `.nvmrc` 22.19.0), Fastify 5, fastify-type-provider-zod, @fastify/cors, rate-limit, swagger, argon2, jose, Zod 4                       |
| Persistence | PostgreSQL 16 (Docker Compose locally), Prisma 7.10 with the `@prisma/adapter-pg` driver adapter, hand-written SQL in migrations                         |
| Tests       | API: Vitest (unit + integration). Mobile: Jest + jest-expo + RN Testing Library (unit), Vitest (integration against the real API + DB)                  |
| Tooling     | npm 10.9.3 workspaces, ESLint 10 + typescript-eslint, Prettier 3, GitHub Actions, Dependabot                                                           |

**Not present:** Playwright or any E2E framework, an API Dockerfile, deployment
configuration, analytics, and AI/LLM SDKs.
